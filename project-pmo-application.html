Project Overview

Why the Project Was Created

The PMO Project Management Application was developed to establish a centralized platform for managing and governing projects across the Facilities Services department. The solution standardized the entire project lifecycle, from project initiation and registration through execution, monitoring, change control, stage-gate reviews and project closure.

Business Problem

Projects were managed through multiple spreadsheets, emails and standalone documents. There was no standardized project registration process, no formal stage-gate approvals, no structured change control process and limited visibility into project progress, budgets and scope changes. This resulted in inconsistent governance, delayed project delivery and difficulty monitoring overall project performance.

Solution

A centralized Project Management Application was implemented to provide a single source of truth for all projects. The solution introduced standardized project registration, digital Project Charters, Stage-Gate Reviews, Change Control workflows, executive dashboards, project workspaces, centralized documentation and Project Closure reporting. This improved governance, increased transparency and enabled leadership to make informed decisions using real-time project data.
